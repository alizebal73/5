# GameNet 98 — مدیریت سرور CS2 (شاخهٔ آزمایشی)

این پوشه، سورس قابل تغییر **Oblivion Server Tool v1.1.5** است که برای مناسب‌سازی جهت GameNet 98 وارد شده است.

## وضعیت فعلی
- سورس اصلی برنامه، API، رابط وب، کنترل سرور و وابستگی‌های پایتون کپی شده‌اند.
- نام برنامه و مسیر تنظیمات از نسخهٔ اصلی جدا شده است.
- نسخهٔ اولیه 0.1.0 است؛ به‌روزرسانی خودکار از مخزن اصلی غیرفعال شده است.
- درخواست فونت از Google حذف شده تا رابط کمتر به اینترنت وابسته باشد.
- نقشهٔ Dust2 گزینهٔ اول نقشه‌های رسمی است.
- رابط نهایی فارسی با دو گزینهٔ «ساخت سرور» و «یافتن سرور» هنوز کامل نیست.
- کشف خودکار سرورهای LAN و اتصال یک‌کلیکی مشتری هنوز پیاده‌سازی و آزمایش نشده است.
- فایل‌های باینری افزونه‌های ثالث عمداً در این مرحله کپی نشده‌اند؛ مجوز هر افزونه باید جداگانه بررسی شود.
- ساخت و اجرای واقعی روی ویندوز هنوز در این محیط تأیید نشده است.

## اجرای توسعه‌ای
در این پوشه محیط Python را آماده و وابستگی‌های `requirements.txt` را نصب کن، سپس اجرا کن:

```bat
python main.py
```

ساخت فایل اجرایی ویندوز با `build.bat` طراحی شده، اما هنوز باید روی ویندوز آزمایش شود.
