# Foundation Certification

Foundation is not certified by file existence or green unit tests alone.

Required evidence before business work:
- clean Windows restore/build/test;
- architecture/source-size/placeholder guards;
- native Desktop launch in fa-IR and en-US;
- real PostgreSQL migration and concurrency lane;
- Agent service start, authenticated connection, reconnect and fencing;
- Desktop -> Server smoke;
- backup and isolated restore smoke;
- update/rollback smoke;
- exact commit evidence recorded in the stable-checkpoint document.

Until these are green, business modules remain empty.
