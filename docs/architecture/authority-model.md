# Authority Model

Customer identity -> Customers
Operator identity/permissions -> Identity/Users
Station -> Stations
Agent device identity/pairing -> Agents
Session ownership/state -> Sessions
Tariff -> Tariffs
Charge/settlement -> Billing
Wallet ledger -> Wallet
Inventory ledger -> Inventory
Audit -> Platform
Durable external events -> Outbox

Desktop and Agent may cache/display/execute, but never replace Server authority.
